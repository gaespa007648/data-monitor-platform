# 文件管理規範

| 位置 | 讀者與用途 | 維護原則 |
| --- | --- | --- |
| README.md | 使用者、部署者與其他專案讀者的入口 | 專案介紹、技術棧、運行、部署、API 與測試帳號資訊；詳細文件連至 docs |
| docs/ | 可分享的架構與操作文件 | 自成一體，依目前程式與設定維護，不依賴內部文件 |
| artifact/ | 開發者自行管理的內部文件 | 規劃草稿、開發過程、驗證與除錯紀錄；不作為對外文件入口或相依來源 |

README 不記錄開發過程、修復歷史、測試執行結果或個人環境紀錄，也不連結或引用 artifact 內容。README 所需的專案補充文件一律整理在 docs；API 執行期入口仍可直接連結 localhost 端點，第三方官方來源則整理在對應 docs 文件中。

docs 同樣不連結 artifact 或以其內容作為正式依據。新增或更新對外文件時，核對程式、compose.yaml、Dockerfile 與 `.env.example` 的實際行為；保留可重複使用的架構及操作資訊，不把開發紀錄直接複製到 docs。

artifact 由開發者自行維護，除非明確要求，不移動、刪除、整理或修改其中的文件；不因 README 清理而搬出內部紀錄。現有版控排除規則維持不變。

文件、連結及範例不得包含實際 `.env` 憑證、密碼雜湊、JWT 或本機絕對路徑。對外文件使用專案相對連結；帳密範例採 `.env.example` 的公開範本值。
